## Subject Purpose

MAST5112 introduces students to **mobile application development** using the **React Native framework** with *TypeScript*.

Throughout this subject, students will:

- Learn how to build cross-platform mobile applications for Android, with iOS development as an optional extension.
- Apply component-based design principles.
- Use state management and event handling to create interactive applications.
- Work with navigation and common application structures.
- Develop working prototypes for practical and real-world scenarios.

Development and testing are performed primarily within a Virtual Machine (VM) environment provided for the subject. The VM is preconfigured with the software required for development, including Visual Studio Code, Node.js, Expo, Android Studio, and BlueStacks.

Students may also install the required software locally on their own machines for development outside the VM environment.

## Learning Material

The material in this repository is developed progressively alongside the subject.

The notes begin with the fundamentals of setting up and running a React Native project before moving into the structure of an application and the development of reusable components.

Topics currently covered or being developed include:

- Project setup and execution
- React Native application structure
- Components and props
- Understanding App.tsx
- State and state hooks
- Layout and styling
- Navigation
- Practical component development
- Small application examples and exercises

Future material may include event handling, lists, external libraries, additional application patterns, and deployment strategies.

The repository is therefore intended to be a living reference that develops alongside the subject rather than a fixed collection of notes.
